Kontrakt wejściowy jest zamrożony w [modelu zestawów](../architecture/exercise-set-model.md).
SET-02 dostarczył niezależny backend zestawów, a SET-03 katalogowy kontrakt wyboru
konkretnej wersji ćwiczenia. Formalne zamknięcie repozytoryjnego verify nadal oczekuje
na naprawę zastanego globalnego cyklu modułów i legacy fixtures po V036.
